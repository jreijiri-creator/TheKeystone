## Vault Structure

| Folder | Purpose |
|---|---|
| `00-Templates/` | Master templates — duplicate these for new clients/sessions |
| `01-Clients/` | One sub-folder per client — contains their OPFMS master + all session notes |
| `02-Forms-Repository/` | All LMI forms as fillable Markdown fields, ready to copy into session notes |
| `03-Assignments/` | Per-lesson assignment briefs you send the client |
| `04-Resources/` | PFS scoring guide, vault how-to |

---

## Quick Start for a New Session

1. Open your client's `OPFMS-[Name].md` — review the **Session Log** and carry-forward items.
2. Duplicate `00-Templates/Session-Note.md` into `01-Clients/[Name]/Sessions/` and rename it `YYYY-MM-DD-Session-XX-LXX.md`.
3. Fill in the **Carry-Forward** section from the previous session note.
4. Score the **Intangibles** at start or end of session.
5. Take notes in **Session Notes** during the meeting.
6. At end of session: choose the lesson/assignment in **Next Session Selector**.
7. Copy the pre-filled **Client Summary** block into `00-Templates/Client-Summary-Email.md` and send/share.

## Quick Start for a New Client

1. Duplicate `00-Templates/OPFMS-Client-Master.md` into a new folder `01-Clients/[Client-Name]/`.
2. Fill in the YAML frontmatter and Participant Profile.
3. Run personality assessment and fill in the Personality Profile section.
4. Define their Intangibles together in session.
